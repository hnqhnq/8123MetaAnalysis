# 第 1 课解读：循证医学概述

课件：`Lesson+1+for+PhD+-+full+version.pdf`（95 页）  
课程：AIHA8123 Artificial Intelligence Driven Meta-Analysis  
教师：饶文旺（Wen-Wang Rao）

这一课建立后面所有系统评价和 meta 分析的出发点：临床决策不是“有一篇文献就照做”，而是把可回答的问题、合适层级的证据、对证据的批判，以及患者本人的情况合在一起。第 1 课结尾才把系统评价和 meta 分析放回证据金字塔的顶端，说明这门课为什么从 EBM 讲起。

## 1. 这一课的主线

课件目录把内容收成八步：

1. 认识并定义 EBM
2. 学会 EBM 的操作步骤

5. 批判性评价证据

## 2. EBM 要解决的问题

历史上的对照是放血疗法。放血约有 3000 年历史，被当作“热、湿”疾病的疗法。Pierre Louis（1787–1872）用“数值方法”比较 77 例急性肺炎患者的病程和结局，发现放血的帮助远小于当时的普遍信念。他是 EBM 的早期先行者。William Osler 写了影响很大的《医学原理与实践》，也认为当时多数药物无用，却仍在部分情形下主张放血。教训是：权威、传统和病理生理上“说得通”，都不能代替对患者结局的系统观察。

临床医生面对的是信息量，不是信息不足。课件引用 Davidoff、Haynes、Sackett、Smith（*BMJ* 1995）的对比：全科医生每周能用来阅读的时间不到 1 小时，而要跟上普通内科，大约需要每天读 19 篇、一年 365 天。另一张图把文献量画成：生物医学文献约每天 5000 篇，MEDLINE 约每天 2000 篇，临床试验约每天 75 篇。医生没有时间读完，教科书过时，最新期刊又散。EBM 提供的是“在需要的时候找到能用的证据”的方法，而不是要求读完所有新文献。

文献从产生到进入常规实践还有很长的滞后期。路径是：原始文献 → 二次研究 → 常规临床实践，滞后可以是数年甚至数十年。课件用急性心肌梗死的溶栓药和阿司匹林作例子：从第一篇 RCT 的系统评价，到多数综述、教科书和专家意见推荐使用，隔了 6 年（Antman 等，*JAMA* 1992）。

## 3. 定义：三件事合在一起

Sackett 1996 年的定义（课件称他为循证医学之父）：

> conscientious, explicit and judicious use of current best evidence in making decisions about the care of individual patients.

中文可记成：有意识、明确、审慎地使用当前最佳证据，为个体患者做决策。它要求把个人临床经验，和来自系统研究的最佳外部临床证据结合在一起。

三角图（Sackett 等，*BMJ* 1996; 312: 71–72）把三块都指向“改善患者结局”：

| 来源 | 作用 |
| --- | --- |
| 当前最佳临床证据 | 底座 |
| 个人临床经验 | 从一侧汇入 |
| 患者的价值观与期望 | 从另一侧汇入 |

少任何一块，就不是课件里的 EBM。证据充分且有益就去做；证据显示无效或有害就不做；证据不足时依靠临床经验，并采取保守做法。

传播方式也在变：

| 阶段 | 方式 | 含义 |
| --- | --- | --- |
| EBM 之前 | 被动扩散 | 发表了，指望别人自己来读 |
| 早期 EBM | 拉动 | 教会临床医生自己去读 |
| 当前 EBM | 推动 | 替临床医生读完，再送到他们面前 |
| 未来 EBM | 提示 | 读完后接到这个具体患者身上 |

兴趣突然变大的原因，课件给了两条：只靠年资、不更新知识，临床水平会下降；在患者更主动的时代，诊断、治疗、预后和预防都需要有效信息。真正卡住更新的，是临床医生没有时间从传统来源里找信息。

### 历史坐标

课件的时间线可以按这个顺序记：

- 约公元 900 年，Al-Razi：有意治疗一组、不治疗另一组，以便得出结论。
- 1780 年前后，James Lind：坏血病的综述与临床试验。
- Pierre Louis：数值方法，并改变了法国的放血实践。
- 1937 / 1948，Bradford Hill：《医学统计学原理》，以及医学研究委员会的链霉素试验。
- 1967，Alvan Feinstein：《临床判断》。
- 1970 年代，McMaster 大学的临床流行病学与生物统计。
- Archie Cochrane（1909–1988）：Cochrane 协作网以他命名。他在 1979 年写道，医学界的重大批评是，我们还没有按专科组织一份定期更新的、对所有相关随机对照试验的批判性总结。
- 1995，病房里的 evidence cart：每个患者查 2–3 个问题，15–90 秒能找到，大约三分之一的决定因此改变。已评价过的题目最快，其次是“最佳证据”资源，直接查 MEDLINE 最慢。

### 课件明确划掉的三种误解

1. EBM 忽视临床经验和直觉。
2. 基础研究和病理生理在 EBM 里没有位置。
3. EBM 忽视病史采集、体格检查等临床训练。

这三件事都仍然要做。EBM 增加的是：在这些工作之外，用当前最佳外部证据约束决策。

## 4. 为什么要做 EBM

课件列了五个压力，后面各有一页展开。

**费用。** 有些机构用治疗流程来压成本，并把它叫做 EBM。临床侧真正增加的压力，是必须证明干预有效。当费用挡住患者时，临床医生需要知道哪些治疗完全无效，从而选择真正划算的办法。

**从实验台到病床的滞后。** 见上一节的溶栓药例子。

**文献管不过来。** 课件给出的数量级是：120 种著名期刊每年约 6 万篇文章；MEDLINE 收录 3800 多种生物医学期刊，每周新增 7300 多条记录；本专业每天要读 19 篇才能跟上；其中大约只有 10% 算得上高质量且与临床相关。EBM 的用处是为这一个临床问题找到最合适的那篇文章。

**对付误导性营销。** 药企会用选择性证据和面向消费者的广告推广产品。临床试验注册能用来发现发表偏倚，也能约束做完试验后再按结果挑选分析的做法。

**结果互相矛盾。** 只靠生理推理、理论，或方法有缺陷的研究，会做出错误预测。例子是心肌梗死后的 β 受体阻滞剂：起初因为担心削弱代偿性交感神经机制而避免使用，后来的证据显示它降低住院和死亡。

采用 EBM 之后，课件在结尾归纳的益处有三条，这是复习要点里的“Benefits of adopting EBM”：

1. 减少差错，提高患者照护质量
2. 降低治疗费用
3. 推进知识，并跟上科学进展

它额外提供的是改变的机会，以及更好治疗的机会。

落地时有三个条件：临床医生要用得到技术和在线资源；要弄清流行病学研究设计和生物统计概念；态度上要承认，临床水平来自持续更新知识，年资本身不够。

## 5. 两套步骤：5A 和五条原则

### 5A

| 步骤 | 做什么 |
| --- | --- |
| Assess | 从照护这个患者中发现临床问题 |
| Ask | 写成结构良好的临床问题 |
| Acquire | 选对资源并检索 |
| Appraise | 检查有效性和适用性 |
| Apply | 与临床经验和患者偏好结合后用到实践中 |

### 7A

在 5A 的环上再加两步：

- **Analyze outcomes**：这次按证据做的行动，在实践里是否真的有效。
- **Add knowledge**：把这次经验和结局变成下次还能用的知识。

循环顺序是：评估患者 → 提出问题 → 获取信息 → 评价证据 → 应用结果 → 分析结果 → 补充知识 → 再回到下一个患者。任何一步都可以退回去重做。

### 五条原则

课件另有一张“Principles of EBM”，和 5A 几乎平行，分类写得更细：

1. 构建好问题，并归入一类：治疗、诊断、病因、预后、预防或费用
2. 在医学文献中找到证据
3. 批判性评价其有效性和有用性
4. 把证据和患者因素整合
5. 评价整个过程

第 5 条对应 7A 里的 Analyze，也对应短片里“用到临床之后还要回头评估表现”。

## 6. 背景问题与前景问题

| | 背景问题 | 前景问题 |
| --- | --- | --- |
| 范围 | 很一般，适用于大多数患者 | 针对这个患者的具体情况 |
| 内容 | 疾病的基本方面：病理生理、病因、基本治疗 | 需要具体知识才能回答 |
| 问法 | 谁、什么、何时、如何 | 四个部件：患者、干预、对照、结局 |
| 谁更常问 | 初学阶段、先把背景弄透 | 有一定临床经验之后，浏览和解决问题时 |

经验越少，问题越偏背景；经验增加后，前景问题变多。多数情况下要先把背景弄清楚，前景问题才问得准。

课堂判断（课件给出了答案）：

| 问题 | 类型 |
| --- | --- |
| 胃肠炎的病因是什么？ | 背景 |
| 口服补液和静脉补液一样有效吗？ | 前景 |
| 怎样判断我的患者脱水了？ | 背景 |
| 婴儿急性尿路感染有哪些症状？ | 背景 |
| 更短疗程的抗生素能否有效治疗尿路感染？ | 前景 |
| 这个发热婴儿能否安全地在门诊治疗？ | 前景 |

判断标准：问的是疾病的一般知识，就是背景；问的是对这个患者做不做某件事、和什么比、看什么结果，就是前景。

## 7. PICO，以及可选的 T / S

PICO 用来把问题在脑子里理清，标出回答它需要的信息，译成可检索的词，并据此修改检索。

| 字母 | 含义 | 要写清楚的内容 |
| --- | --- | --- |
| P | Patient, Population, Problem | 这组和你的患者最像的关键特征 |
| I | Intervention, Exposure, Prognostic factor | 打算做的事：用药、做检查、某种暴露或预后因素 |
| C | Comparison | 拿来比较的主要替代方案，常是标准治疗或标准检查 |
| O | Outcome | 希望改善或测量的结局，要具体 |
| T | Time，或研究类型（可选） | 时间框架；这个问题最好由哪类研究回答 |
| S | Study design（PICOS） | 和 T 里的研究类型同一类补充，后面做系统评价时会单列 |

### 课件里的三个完整例子

**例 1，治疗问题。** Mary 52 岁，2 型糖尿病 8 年，二甲双胍后血糖明显改善。她 45 岁的弟弟 John 新诊断 2 型糖尿病，问自己要不要也开始用二甲双胍。

| | 内容 |
| --- | --- |
| P | 成人 2 型糖尿病 |
| I | 二甲双胍 |
| C | 不用二甲双胍，或只做生活方式调整 |
| O | 血糖控制改善 |
| 问题 | 二甲双胍在成人 2 型糖尿病的管理中有没有地位？ |

**例 2，外推要小心。** Ali 30 岁，4 岁时诊断心力衰竭，用 β 受体阻滞剂后症状明显好转。他 5 岁的女儿 Leda 最近被诊断为慢性症状性心力衰竭，Ali 问女儿是否也该用。

| | 内容 |
| --- | --- |
| P | 患充血性心力衰竭的儿童 |
| I | 卡维地洛（一种 β 受体阻滞剂） |
| C | 不用卡维地洛 |
| O | 心力衰竭症状改善 |
| 问题 | β 受体阻滞剂在儿童心力衰竭的管理中有没有地位？ |

成人的获益不能自动挪到儿童身上，所以 P 必须写成儿童，不能写成“心力衰竭患者”。

**例 3，练习：首次惊厥后再发风险。** 儿童惊厥常见，家长害怕。要决定第一次发作后要不要开始预防治疗，需要向家长解释：原因不明的单次惊厥之后，再次发作的风险有多高。

| | 课件答案 |
| --- | --- |
| P | 儿童 |
| I | 一次原因不明的惊厥（这里是暴露 / 指示，不是一种治疗） |
| C | 没有惊厥 |
| O | 再次惊厥 |
| 问句 | 与从未惊厥的儿童相比，发生过一次原因不明惊厥的儿童，再次惊厥的风险增加多少？ |

这是预后问题。I 格里放的是“已经发生的情况”，不是医生要开的药。

## 8. 问题类型决定该找哪类研究

| 问题类型 | 在问什么 | 优先的研究设计 |
| --- | --- | --- |
| Therapy 治疗 | 治疗或预防措施是否有效 | RCT > 队列 > 病例对照 > 病例系列 |
| Diagnosis 诊断 | 检查预测疾病的能力 | 队列研究中，与金标准做前瞻、盲法比较 |
| Etiology / Harm 病因或伤害 | 暴露或治疗造成不良结局的可能性 | RCT > 队列 > 病例对照 > 病例系列 |
| Prognosis 预后 | 某病患者的结局 | 队列 > 病例对照 > 病例系列 |
| Prevention 预防 | 预防是否有效 | 与治疗相同：RCT 优先 |
| Cost 费用 | 值不值 | 经济学分析 |

另一张表把“诊断”再拆开，避免和上面的诊断行打架：

- 要评价检查的准确性：队列研究
- 要评价检查对健康结局的影响：随机对照试验
- 预后：队列研究
- 病因、危险因素、伤害：随机对照试验、队列研究或病例对照研究都可以，按可行性和偏倚风险往下排

伤害问题常常不能做 RCT（不能故意把人暴露于危害），所以队列和病例对照是实际可用的设计。治疗问题能随机就应优先 RCT。

## 9. 证据放在哪里：三套分法

课件连续用了三套名字。考试如果问“证据分类”，先看题目用的是哪一套。

### 9.1 一次、二次、三次文献

这是按文献加工深度分的，和证据金字塔不是同一根轴。

| 层次 | 课件定义 | 例子 |
| --- | --- | --- |
| 一次文献 Primary | 同行评议期刊上的原始研究和论文 | 一篇 RCT 原文 |
| 二次文献 Secondary | 用来系统定位已发表文献的索引和摘要服务 | MEDLINE / PubMed、Cochrane Library、Ovid、Embase |
| 三次文献 Tertiary | 已被接受为社区标准的核心知识 | *Harrison's*、医师案头参考（PDR） |

这里的“二次文献”是数据库，不是系统评价。证据金字塔和 EBM 短片里，系统评价和 meta 分析才被叫做二次文献。两处用词不同，答题时要按题目所在的那一页。

### 9.2 四类证据

| 类别 | 是什么 | 例子 |
| --- | --- | --- |
| Studies | 未过滤的原始研究 | MEDLINE、PubMed |
| Summaries | 系统评价 | Cochrane |
| Synopses | 预先评价过的期刊 | ACP Journal Club |
| Systems | 整合进决策的系统 | Clinical Evidence、UpToDate |

这张幻灯片把系统评价叫做 Summaries。下一张 Haynes 的 5S 里，系统评价叫 Syntheses，Summaries 指的是循证教科书。同一个英文词在两页上不是同一个东西。

### 9.3 Haynes 的 5S

来源：Haynes RB. *ACP Journal Club* 2006; 145(3): A8–A9。越往上，别人替你做的筛选和综合越多，你自己花的时间越少。课件标题写的是上面四层才是实践中优先使用的信息。图上的 POCRaTs 箭头从顶端弯下来，指向 Syntheses 这一层。

| 层 | 内容 | 课件举例 |
| --- | --- | --- |
| Systems | 计算机化决策支持 | CDSS |
| Summaries | 循证教科书，已把证据综合进一个主题 | UpToDate、DynaMed、ACP PIER、BMJ Clinical Evidence |
| Synopses | 循证期刊，对单篇研究或综述做结构化摘要 | *EBM*、*EBN*、*EBMH*、ACP Journal Club |
| Syntheses | 系统评价 | Cochrane 综述 |
| Studies | 原始文章 | BMJUpdates、PubMed、Clinical Queries |

检索习惯是先从上面找。上面没有，再往下。

### 9.4 研究设计金字塔

从下到上，数量变少，偏倚通常更可控：

背景信息、专家意见、非循证指南 → 单个病例报告 → 病例系列 → 队列研究 → 非随机对照试验 → 随机对照试验 → 批判性评价文献与循证实践指南 → 系统评价 → meta 分析

另一张更短的金字塔是：社论与专家意见 → 病例系列和病例报告 → 病例对照 → 队列 → RCT → 系统评价。课件直接写：在循证医学里，系统评价和 meta 分析处于证据的最高层。

这是设计上的优先顺序，不是“只要在顶上就一定对”。一篇方法很差的系统评价，可以不如一篇做得好的 RCT。后面的课会用偏倚风险和 GRADE 把“设计等级”和“这项证据到底有多可信”分开。

### 9.5 过滤与未过滤

| 位置 | 时间、工作量、证据量 | 课件标出的资源 |
| --- | --- | --- |
| 上层，已过滤 | 时间少、工作少、证据也更少（因为已经筛过） | Cochrane Library、Essential Evidence Plus、UpToDate、TRIP、PubMed Clinical Queries |
| 下层，未过滤 | 时间多、工作多、证据更多 | Google Scholar |
| 最底 | | 专家意见 |

PubMed 截图把 **Clinical Queries** 标成推荐的检索入口。TRIP 同时提供普通检索和按 PICO 分栏检索（人群、干预、对照、结局）。

未过滤资源：

- PubMed / MEDLINE：来自同行评议期刊；用 Clinical Queries 缩小到临床问题。
- Google Scholar：能覆盖灰色文献，按被引次数排序。优点是覆盖期刊、书、预印本，能导入文献管理软件，能看谁引用了它。缺点是没有主题词，结果极多，不能勾选后批量下载，相关度按被引排序，容易偏向较老的文献。

已预先评价的资源：

- 付费：ACP Journal Club；BMJ Clinical Evidence
- 免费：Cochrane Library；National Guidelines Clearinghouse（AHRQ）；BestBETs；TRIP

Sydney Burwell 的话放在检索这一节开头：今天教给医学生的东西，十年后会有一半被证明是错的，麻烦在于谁也不知道是哪一半。所以检索的是当前证据，不是背住教科书。

## 10. 批判性评价

不论哪一类问题，先问三句：

1. 结果有效吗？（内部真实性）
2. 结果是什么？（效应有多大、有多精确）
3. 结果能帮我照顾这个患者吗？（适用性）

治疗问题的第三组问题，在课件里写在“结果是什么”那一页的后半，内容其实是适用性。下面按课件的原分组列出。

### 治疗

结果是否有效：

- 患者是否被随机分配
- 分配方案是否隐藏（分配隐藏，不是盲法）
- 开始时各组是否相似
- 盲法做到什么程度
- 随访是否完整
- 是否按最初分配的组进行分析（意向性分析）
- 除了研究干预，各组其他治疗是否相同

结果与适用性：

- 效应有多大：相对危险度降低、绝对危险度降低、需治疗人数
- 估计有多精确：置信区间
- 研究对象是否像我关心的人群
- 临床重要的结局是否都看了
- 获益是否值得伤害和费用

### 诊断

结果是否有效：

- 是否与参考标准做了独立、盲法的比较
- 样本是否覆盖将来真正会用这项检查的那类患者（疾病谱是否合适）
- 不论这项检查的结果如何，是否所有患者都做了同一个参考标准
- 检查方法是否写得清楚，别人能够重复

结果与适用性：

- 计算似然比：这项检查能把验前概率改动多少
- 在我的环境里能否重复、能否正确解读
- 结果会不会改变我的处理
- 患者会不会因此更好

### 伤害

结果是否有效：

- 除了感兴趣的那个因素，比较组在其他重要预后因素上是否相似
- 结局和暴露在各组是否用同样的方法测量
- 随访是否完整

结果与适用性：

- 用相对危险度或比值比看暴露和结局的关联有多强
- 有没有剂量反应关系
- 风险的幅度有多大
- 对你这样的患者，利和害如何平衡

### 预后

结果是否有效：

- 样本是否有代表性、定义是否清楚
- 纳入和排除标准是否写清
- 是否调整了重要的预后因素
- 结局标准是否客观、无偏

结果与适用性：

- 看绝对风险（如 5 年生存率）、相对风险（某个预后因素带来的风险），或随时间累积的事件（生存曲线）
- 可能的结局是什么，随时间发生的可能性有多大
- 结果能否直接用来选择治疗
- 能否用来和患者讨论

课堂发的批判性评价工作表把上面这些收成一张纸：临床情景、PICO、问题类型及对应的理想研究设计、检索式和数据库、文献题录、研究类型、有效性核对（是不是它声称的设计、执行是否妥当、有无统计错误、有无其他问题）、临床结果、是否适用于我的患者、结论。表下注明：能找到 meta 分析和系统评价时，它们常常给临床问题提供最好的答案。

## 11. 用回这个患者

评价结束后做三件事：

1. 根据证据，对这个临床问题得出结论
2. 回到这一个患者，而不是停在“文献的平均患者”
3. 把证据、临床经验、同情心和患者价值观合在一起

患者价值观：每个患者带到就诊里的独特偏好、顾虑和期望；要做出真正为这个患者服务的共同决策，就必须把它们纳进去。患者处境指的是这个人当下的临床状态和就诊场景。

## 12. 课的结尾：EBM 是什么，以及为什么接下来做 meta 分析

### EBM 是什么

| 课件说它不是 | 课件说它是 |
| --- | --- |
| “烹饪书”式医学；僵硬地遵守临床指南 | 一套严格、系统的方法，用来判断现有证据对这个临床情境有多强、有多合适 |
| 管理式医疗；削减费用的手段 | 在具体场景里同时看效力、效果和费用，从而避免浪费 |
| 临床流行病学或生物统计本身 | 建立在这些概念之上，以便更好地理解现有证据能支持多强的推断 |
| 只承认 RCT | 承认有些设计（尤其是 RCT）更不容易受偏倚误导，同时其他证据在了解其局限之后仍然用于决策 |

### 为什么要做 meta 分析

系统评价和 meta 分析位于证据金字塔顶端之后，课件给出做 meta 分析的理由：

- 提高把握度
- 确定究竟有没有效应
- 弄清效应有多大，以及围绕它的不确定性有多大
- 检查效应在各项研究之间是否一致
- 处理表面上互相矛盾的研究，或由此产生新的假设

第 2 课从这里接着讲系统评价和 meta 分析的做法。

## 13. 和复习要点的对应

| 要点 | 第 1 课里要能答出的内容 |
| --- | --- |
| 5A | Assess、Ask、Acquire、Appraise、Apply；能说出 7A 多出的 Analyze outcomes 和 Add knowledge |
| PICOS | P、I、C、O，加上研究设计；能把三个例子拆开，尤其是儿童惊厥那题的 I 是暴露不是治疗 |
| 证据分类 | 四类（Studies、Summaries、Synopses、Systems）和 5S 都要会；注意 Summaries 在两页上指的不是同一个东西 |
| 采用 EBM 的益处 | 减少差错并提高照护质量；降低治疗费用；推进知识并跟上进展 |

## 14. 答题时容易混的地方

1. **分配隐藏和盲法。** 治疗问题的有效性清单里，两条都在。分配隐藏发生在分组之前，防止研究者预知下一例会分到哪组；盲法发生在分组之后，防止患者、实施者和结局评价者知道分到了哪组。
2. **Summaries 一词。** 四类证据那页用它指系统评价；5S 那页用它指 UpToDate 这类循证教科书，系统评价在 Syntheses。
3. **二次文献。** “一次 / 二次 / 三次文献”那页的二次文献是 PubMed、Embase 这类索引库。证据金字塔里位于顶端的二次研究，指的是系统评价和 meta 分析。
4. **诊断该找什么研究。** 问准确性，找与金标准的前瞻盲法比较；问这项检查会不会改善健康结局，找 RCT。
5. **金字塔顶端不等于这篇综述一定可信。** 第 1 课只建立“设计上谁更优先”。一项证据最终有多可信，要等后面的偏倚风险和 GRADE。
6. **背景题里的“怎样判断脱水”是背景问题。** 它问的是识别疾病的一般方法，还没有形成“这个患者、这项检查、对照、结局”的前景结构。

## 15. 总结

第 1 课回答的是：面对每天成千上万篇新文献，临床决策怎样才算负责任。Sackett 的定义把三件事绑在一起：当前最佳外部证据、个人临床经验、患者的价值观与处境。三者汇合的目的，是改善这一个患者的结局。证据显示有效就做，显示无效或有害就不做，证据不足时依靠经验并采取保守做法。临床经验、病理生理、病史和查体都留在这个框架里面。

操作上按 5A 走：从患者身上发现问题，写成可检索的问题，选对资源去找，检查结果是否有效、效应有多大、能否用到这个人身上，再和经验与偏好一起用回去。7A 在用完之后还要看这次做法是否真的有效，并把经验变成下次还能用的知识。五条原则把同一过程写成：分类问题、找文献、批判性评价、整合患者因素、评价全过程。

问题要先分清背景和前景。背景问题问疾病的一般知识；前景问题才拆成 PICO。P 写得越像眼前这组患者，后面的证据才越不会被错用，成人有效的 β 受体阻滞剂不能自动开给儿童。可选的 T 或 S 用来标明时间和研究设计。问题属于治疗、诊断、病因、预后、预防还是费用，决定优先找哪一类研究：治疗和预防优先 RCT，预后优先队列，诊断的准确性要和金标准做前瞻盲法比较，诊断对健康结局的影响则要 RCT。

找到证据之后先用上层、已经过滤过的资源：决策支持系统、循证教科书、循证期刊摘要、Cochrane 系统评价；不够再下到 PubMed 和 Clinical Queries。研究设计金字塔从专家意见往上走到系统评价和 meta 分析，数量变少，偏倚通常更可控。评价任何一篇文献都回到三问：结果有效吗，结果是什么，对我这个患者有没有用。

采用 EBM 的直接益处是三条：减少差错并提高照护质量，降低治疗费用，推进知识并跟上科学进展。它成立的条件是资源用得到、能看懂研究设计和统计、并且承认临床水平来自持续更新。系统评价和 meta 分析站在这套逻辑的顶端：提高把握度，确认有没有效应、效应有多大、在各研究之间是否一致，并处理互相矛盾的结果。第 2 课从这里开始讲怎样真正做一次系统评价。

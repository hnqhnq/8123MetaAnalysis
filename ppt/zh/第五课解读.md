# 第 5 课解读：偏倚风险与 GRADE

课件：`Lesson 5 for  PhD - full version123.pptx`（84 页）  
课程：AIHA8123 Artificial Intelligence Driven Meta-Analysis  
教师：饶文旺（Wen-Wang Rao）

第 4 课决定哪些研究进入综述。这一课问这些研究的结果能不能信，以及把多项研究放在一起之后，对效应估计有多大把握。前半从“研究质量”转到偏倚风险，重点是 Cochrane RoB 2。后半用 GRADE 给一整组证据定级，并把它和推荐强度分开。

课件开头有一段与第 4 课后半相同的 EndNote 操作页。新内容从系统评价的关键特征开始：目标和方法可重复、系统检索、评价纳入研究的效度（例如偏倚风险）、系统呈现并综合结果（Liberati 等，*BMJ* 2007）。

复习要点里，这一课对应 GRADE 的 3 个升级因素和 5 个降级因素。偏倚风险是降级的第一项。

## 1. 质量评价和偏倚风险

原始研究的方法学质量可能影响结果，所以系统评价要常规检查质量的影响。质量本身很难界定：它可能指试验的设计、实施和分析，也可能指临床相关性，或报告质量，或这几样一起。本课把焦点放在随机对照试验。

偏倚是偏离真实情况。干预实际上没有效果，研究却显示出效果，就是偏倚。课件用靶图区分两件事：弹着点散但围着靶心，是不精确但准确；弹着点很集中却偏离靶心，是精确但不准确。偏倚风险针对的是后一种系统误差。

| | 质量评价 | 偏倚风险评价 |
| --- | --- | --- |
| 范围 | 对研究质量和可靠性的宽泛评价 | 集中评价可能的系统误差 |
| 看什么 | 设计、实施、分析、报告；常见条目还有样本量、资料收集、统计分析、结果是否一致、可推广性、随访、报告是否清楚 | 可能扭曲效应估计的偏倚领域：选择、实施、测量、失访、报告 |
| 得出什么 | 对研究做得好不好的总体判断 | 结果在哪些地方可能被带偏；关注可信程度和内部效度 |

2005 年 Cochrane 认为质量评分没有帮助，评价应集中在真正可能带来偏倚的环节，例如分配隐藏、结局评价的盲法、失访的处理。这些条目要和异质性、不精确分开：后两者不是这一工具要判的偏倚。

## 2. 按研究设计选工具

评价工具和报告规范不是同一张表。左边评做得怎么样，右边规范写得怎么样。EQUATOR 网络按研究类型收录报告规范。

| 设计 | 方法学工具 | 报告规范 |
| --- | --- | --- |
| 动物实验 | SYRCLE RoB | ARRIVE |
| 随机对照试验 | Cochrane RoB | CONSORT |
| 非随机研究 | MINORS | TREND |
| 病例对照 | Newcastle–Ottawa（NOS） | STROBE |
| 队列 | Newcastle–Ottawa（NOS） | STROBE |
| 诊断准确性 | QUADAS-2 | STARD |

EQUATOR 页面上还能看到方案用 SPIRIT、系统评价用 PRISMA、病例报告用 CARE、定性研究用 SRQR、卫生经济评价用 CHEERS。

质量量表和清单超过 40 种，复杂程度差别很大。许多量表把试验质量、报告质量和其他方面（例如样本量）混在一个分数里。Jadad 1996 很常用，0 到 5 分，但课件指出它的严重缺陷是把方法学和报告绑在一起。同一批试验被分成高质量或低质量，结果强烈取决于用哪一把尺子（Jüni 等，*JAMA* 1999）。

## 3. 改良 Jadad 量表

第 2 课讲过经典 Jadad 的三项、满分 5 分。这一课给出八项改良表和每一格的分数。随机方法和盲法方法如果描述了但不恰当，要减分。脚注：双盲记 1 分，单盲记 0.5 分。

| 条目 | Yes | No | 未描述 |
| --- | --- | --- | --- |
| 是否描述为随机 | +1 | 0 | |
| 随机方法是否恰当 | +1 | −1 | 0 |
| 是否描述盲法 | +1（双盲 1，单盲 0.5） | 0 | |
| 盲法方法是否恰当 | +1 | −1 | 0 |
| 是否描述退出和失访 | +1 | 0 | |
| 纳入和排除标准是否清楚 | +1 | 0 | |
| 是否描述不良效应的评价方法 | +1 | 0 | |
| 是否描述统计分析方法 | +1 | 0 | |

八项都取到加分时合计 8 分。两个“方法是否恰当”的条目可以是 −1。这张表仍然是评分。课件前面已经说明，Cochrane 后来不用一个总分代表偏倚风险。

## 5. RoB 2

RoB 2 要回答的是：方法是否可靠，因此报告的结果是否可信，以及可信到什么程度。

原则：

- 对每项研究的每一个关键结果都评偏倚风险
- 判断要有支持性资料，而且透明
- 写明支持性资料的来源
- 有的偏倚在研究层面，例如随机化过程
- 至少由两人完成

五个领域：

| 编号 | 领域 |
| --- | --- |
| D1 | 随机化过程中的偏倚 |
| D2 | 偏离既定干预造成的偏倚 |
| D3 | 结局数据缺失造成的偏倚 |
| D4 | 结局测量中的偏倚 |
| D5 | 结果选择报告中的偏倚 |

每个领域的做法是：先回答信号问题，再由算法给出风险判断，用文字说明理由，并可选地预测偏倚可能的方向。信号问题的答案是：Yes，Probably yes，Probably no，No，No information。

### D1 随机化

三个问题：分配序列是否随机；分配序列是否被充分隐藏；基线差异是否提示随机过程有问题。

算作随机的做法包括计算机随机数、随机数字表、抛硬币、洗牌、掷骰子、抽签。算作充分隐藏的做法包括远程或中心化分配、不透明且顺序编号的密封信封、顺序编号且外观相同的药瓶。提示有问题的基线情况包括：两组人数相差很大，基线特征有大量显著差异，预后因素的不平衡不太可能只是机遇。

算法把这些答案收成 Low、Some concerns 或 High。序列随机、隐藏充分、基线不提示问题时，判断为低风险。图上的高风险路径连到“序列不随机”以及“隐藏不充分且基线提示有问题”。

### D2 偏离既定干预

先决定综述要估计的是哪一种效应。课件把“分配到干预的效应”圈出来，也就是意向性分析；另一支是“依从干预的效应”，也就是符合方案分析。两套信号问题不同。

分配效应这一支的前半问：参与者是否知道自己的分配；实施干预的人员是否知道；是否因为试验情境而产生偏离；偏离是否影响结局；偏离在两组之间是否平衡。后半问：是否用了适合“分配效应”的分析；没有按随机分组分析时，是否可能对结果有实质影响。

参与者和实施者都不知道分配时，这一领域可以到低风险。知道分配之后，还要看有没有因试验情境产生、并且影响结局、而且两组不平衡的偏离。分析必须估计分配效应；该按随机分组分析却没有这样做，并且可能实质影响结果时，算法走向高风险。

### D3 结局数据缺失

四个问题：是否所有参与者都有结局数据；是否有证据表明结果没有被缺失数据带偏；缺失是否可能取决于结局的真实值；是否很可能已经取决于真实值。

“全部都有”在说明里包括：缺失人数少到不可能改变重要结论。证明“没有被带偏”的证据可以是校正了偏倚的分析，或在一系列合理假设下结果几乎不变的敏感性分析。失访或退出若与健康状况有关，缺失就可能取决于真实值。两组缺失比例不同、缺失原因说明它取决于真实值、两组报告的缺失原因不同，都支持“很可能取决于真实值”。

数据基本完整时为低风险。不完整但有证据表明结果没被带偏，也为低风险。缺失可能取决于真实值、并且很可能已经取决于真实值时，为高风险。中间情况为 Some concerns。

### D4 结局测量

五个问题：测量方法是否不恰当；测量是否在两组之间不同；结局评价者是否知道分组；评价是否可能受这种知情的影响；是否很可能已经受影响。

方法不恰当的例子是结局对干预不敏感，或工具效度差。测量不同的例子是被动收集数据造成的诊断检出偏倚，以及干预组因为额外访视而有更多机会被测到结局。评价者是否设盲，决定他们知不知道分组。知情更可能影响主观结局；死亡这类客观结局通常不受影响。测量方法不恰当，或两组测量不同并且评价很可能受知情影响时，算法可以到高风险。

### D5 选择性报告结果

三个问题：是否按预先写好的分析计划分析；结果是否从多个测量里挑出来；结果是否从多种分析里挑出来。

按预定计划分析，并且不是从多个测量或多种分析里挑选时，为低风险。从多个测量或多个分析里挑选了所报告的结果，为高风险。计划不清楚、又不能确认有挑选时，为 Some concerns。

选择性报告的背景是：统计上显著的结局更容易被报告出来（Kirkham 等，*BMJ* 2010）。发现它最好有研究方案；论文内部或试验注册库也可能提供证据。旧版工具在缺少方案时，这一条通常只能判 Unclear。

### 总判断

总判断针对某一个具体结局。

| 总判断 | 标准 |
| --- | --- |
| Low | 该结果的全部领域都是低风险 |
| Some concerns | 至少一个领域为 Some concerns，且没有任何领域为高风险 |
| High | 至少一个领域为高风险；或者多个领域为 Some concerns，并且因此实质降低了对结果的信心 |

课件把“高风险”这一格圈出。一个领域高，总体就是高。多个领域只是“有些顾虑”，只要这些顾虑实质降低信心，总体也是高。

Cochrane 的 Excel 工具（课件截图为 RoB 2 评估表，含 Summary、Figures、Discrepancy Check）用来填写信号问题并生成判断。robvis 是把这些判断画成图的网页工具。课件的 RoB 2 例图同时有逐研究的交通灯和按领域汇总的条形图：绿为 Low，黄为 Some concerns。交通灯上 D2 为黄的研究，Overall 也是黄，对应“有一个领域为 Some concerns、没有高风险”。

### 模拟研究

课件给了一项模拟试验，没有直接印出判断。按上面的信号问题，五项都支持低风险，因此总体也是低风险。

200 名参与者 1:1 分到药物 A 或外观相同的安慰剂。独立统计人员用计算机产生序列，中心随机系统实施，招募人员不能预知下一分配，基线差异不提示随机有问题。参与者、实施人员和结局评价者均设盲，盲法保持到结束。200 人全部完成第 8 周血压测量，都按原分配组分析，随机后没有人被排除。两组使用同一台经过验证的电子血压计和同一套测量程序。方案和统计分析计划在揭盲前定稿，写明了结局、评估时点和分析方法；报告的结果遵循该计划，没有按结果挑选测量、时点或分析。

| 领域 | 这份描述支持的判断 |
| --- | --- |
| D1 | 低：计算机序列、中心隐藏、基线不提示问题 |
| D2 | 低：各方设盲且盲法保持；全部按随机分组分析 |
| D3 | 低：200 人全部有第 8 周结局 |
| D4 | 低：测量方法恰当且两组相同，评价者设盲 |
| D5 | 低：揭盲前的计划被遵守，没有挑选结果 |
| 总体 | 低：五个领域都是低 |

## 6. 其他清单

CASP 按设计提供清单，课件列出：系统评价、诊断、定性研究、队列、随机对照试验、经济评价、病例对照、临床预测规则。这些是批判性评价清单。RCT 的偏倚风险这一课用 RoB 2，不把 CASP 的“是或否”加总成分数。

## 7. GRADE

分级是因为人们会同时对证据质量和推荐强度下结论。明确、系统的做法有助于批判性评价、减少错误、解决分歧，并把信息传达出去（GRADE Working Group，2004）。

GRADE 是一套通用语言，由 GRADE 工作组制定并更新，被许多组织采用。它表达两件事：对证据质量有多大信心，以及对推荐有多强的信心。证据质量根据研究设计，再加上降级和升级标准来评（Guyatt 等，2008）。

证据质量的定义是：对效应估计有多大信心。

| 等级 | 符号 | 含义 |
| --- | --- | --- |
| 高 | ++++ | 很有信心，真实效应接近估计值 |
| 中 | +++ | 中等信心。真实效应很可能接近估计，但有可能实质不同 |
| 低 | ++ | 信心有限。真实效应可能与估计实质不同 |
| 极低 | + | 几乎没有信心。真实效应很可能与估计实质不同 |

起点：

- 一组随机对照试验从“高”开始
- 其他研究设计从“低”开始
- 随机试验和观察性研究通常分开评价

图上还单列了病例报告、专家意见和模型，放在观察性研究之下。文字规定的起点仍是两档：RCT 为高，其余为低。

五个因素可以降级，三个因素可以升级。每一项降级可以是 −1 或 −2。

| 降级因素 | 在看什么 | −1 | −2 |
| --- | --- | --- | --- |
| 偏倚风险 | 与该结局有关的设计或实施局限，来自单项研究的质量评价 | 多数研究为中或高偏倚风险，局限严重 | 局限非常严重 |
| 不一致性 | 各研究效应估计是否相似 | 很大且不能解释的不一致 | 非常大且不能解释的不一致 |
| 间接性 | 人群、干预、对照、结局与真正关心的问题有多接近 | 对直接性有严重不确定 | 非常严重的不确定 |
| 不精确 | 由样本量和事件数决定 | 数据不精确或稀疏 | 非常不精确或非常稀疏 |
| 发表偏倚 | 选择性发表使效应被系统高估或低估 | 强烈怀疑 | 非常强烈怀疑 |

不一致的迹象包括效应方向不同、效应大小差别大、I² 很大。能用人群、干预或结局解释的异质性，和不能解释的异质性要分开，降级针对后者。

间接的迹象包括人群差别很大（年龄、性别、疾病）、用了替代结局、没有直接比较。

不精确的迹象包括人群小、事件少、合并效应的置信区间很宽，例如把 RR = 1 包括在内。

发表偏倚的迹象包括研究小、由企业资助、漏斗图不对称。

三个升级因素：

| 因素 | 课件给出的条件 |
| --- | --- |
| 效应大 | +1：相对风险降低 ≤ 0.5，或风险比 ≥ 2。+2：相对风险降低 ≤ 0.8，或风险比 ≥ 5。大效应或极大效应更不容易是假象 |
| 剂量反应 | 观察到剂量反应梯度，+1 |
| 残余混杂的方向 | 观察到效应时，所有合理的残余混杂和偏倚都会把效应缩小；没有观察到效应时，它们都会把效应加大。方向符合时 +1 |

升级主要用于从“低”起步的观察性证据。随机试验和观察性研究分开走这张表。

课件后部给出 GRADEpro GDT 的注册界面，语言可以选中文。它是制作 GRADE 证据表的工具。具体一张表怎么从高降到低，课件留了标题，计算例在后面的课。

## 8. 推荐强度

推荐强度的定义是：遵守这条推荐时，有多大信心认为期望效果超过不良效果。

| 强度 | 含义 |
| --- | --- |
| 强推荐 | 小组有信心：期望效果超过不良效果 |
| 弱推荐，也叫有条件的或酌情的推荐 | 小组认为期望效果大概超过不良效果，但没有信心 |

证据质量和推荐强度是两件事。质量看对这一组证据有多大信心。强度看这份信心，再加上其他考虑。四种组合都可能出现：高质量证据可以对应弱推荐，极低质量证据可以对应强推荐。课件指出，没有高质量证据却作出强推荐的典型情形见 Alexander 等，2016。这一页没有把那些情形展开。

## 9. 和复习要点的对应

| 要点 | 第 5 课里要能答出的内容 |
| --- | --- |
| GRADE 的 3 个升级因素 | 效应大、剂量反应、残余混杂和偏倚的方向有利 |
| GRADE 的 5 个降级因素 | 偏倚风险、不一致性、间接性、不精确、发表偏倚 |
| 证据质量的四档 | 高、中、低、极低；RCT 从高开始，其他设计从低开始 |
| 偏倚风险 | RoB 2 的五个领域和总判断规则；它是 GRADE 降级的第一项 |

## 10. 答题时容易混的地方

1. **质量评分和偏倚风险。** 改良 Jadad 给出一个分数。RoB 2 不给总分，它按结局、按领域判断。样本量小、报告写得不清楚，可以算进广义的质量，但不是 RoB 2 的一个领域。
2. **旧版和新版。** 第 2 课和本课的条形图是旧版：低、不清楚、高，领域里有“其他偏倚”，盲法按主观结局和死亡分开。RoB 2 是五个领域，判断是低、有些顾虑、高。信号问题可以答 No information，这不是领域判断里的 Unclear。
3. **总判断。** 一个领域高，总体就是高。全部领域都低，总体才是低。只有一个领域是 Some concerns、其余为低时，总体是 Some concerns。多个 Some concerns 如果实质降低信心，总体可以是高。
4. **D2 先选定效应类型。** 课件圈出的是分配效应，也就是意向性分析。符合方案分析是另一套问题。没有按随机分组分析，影响的是这一领域。
5. **D3 和 D4。** 缺失数据是 D3。测量工具不合适、两组测法不同、评价者知道分组，是 D4。死亡通常不受评价者知情的影响，主观结局会。
6. **选择性报告的两种说法。** 旧版在没有方案时常常只能写 Unclear。RoB 2 的 D5 仍要在低、有些顾虑和高之间作判断：按预定计划且没有挑选，为低；确认从多个测量或多种分析中挑选，为高。
7. **工具和规范。** CONSORT、STROBE、PRISMA、STARD 规范的是怎么写。Cochrane RoB、NOS、QUADAS-2 评价的是偏倚或方法学。诊断研究用 QUADAS-2 和 STARD。队列和病例对照的方法学工具都是 NOS，报告规范都是 STROBE。
8. **证据质量和推荐强度。** 高质量可以对应弱推荐，极低质量可以对应强推荐。GRADE 的等级描述的是对效应估计的信心，不是推荐本身强不强。
9. **升级条件里的不等号。** 课件印的是：+1 为相对风险降低 ≤ 0.5 或风险比 ≥ 2；+2 为相对风险降低 ≤ 0.8 或风险比 ≥ 5。风险比 ≥ 2 和 ≥ 5 是效应很大的方向。相对风险降低若理解成“降低了多少比例”，≤ 会把较小的降低也包括进去，和“效应大才升级”的方向相反。答题时先按课件原文写这四个数，同时知道常见 GRADE 叙述里，大效应是风险比 ≥ 2 或 ≤ 0.5，极大效应是 ≥ 5 或 ≤ 0.2。
10. **精确和准确。** 置信区间很宽是 GRADE 的不精确，用来降级。弹着点集中但偏离靶心是偏倚。两项可以同时存在，降级时分属不同因素。

## 11. 总结

第 5 课把单项研究的偏倚和整组证据的信心分开。质量一词太宽，又常和报告质量、样本量混成一个分数，所以 Cochrane 改为评价偏倚：结果偏离真实情况的风险。随机对照试验用 RoB 2，由至少两人、针对每一个关键结果，在随机化、偏离既定干预、结局缺失、结局测量和选择性报告五个领域作判断。信号问题的答案进入算法，得到低、有些顾虑或高。全部为低则总体为低；任一领域为高，或多重有些顾虑已实质降低信心，则总体为高。模拟的降压试验五个领域都满足低风险的条件。旧版交通灯仍要认得，但它用的是不清楚，并且保留“其他偏倚”。改良 Jadad 是八项评分，最高路径合计 8 分，不能代替 RoB 2。

GRADE 评价的是一组证据。随机试验从高开始，其他设计从低开始，再按偏倚风险、不一致性、间接性、不精确和发表偏倚降级，按大效应、剂量反应和有利的残余混杂升级。四级是高、中、低、极低，表示对效应估计的信心。推荐可以强，也可以弱。证据等级低时仍然可以作出强推荐，证据等级高时也可以只作出弱推荐。
